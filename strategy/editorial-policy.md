# 편집 정책 (초안)

작성일: 2026-09-29 · 상태: **초안 (사용자 검토 대기)**. 사이트 공개 시 "방법과 원칙" 페이지의 원문이 된다.
관련 문서: [content-media-architecture.md](content-media-architecture.md) · [../research/ai-monetization-landscape.md](../research/ai-monetization-landscape.md) §13 (수익화 편집 원칙 R1~R14)

## 1. 기본 입장

> **AI를 활용해 만드는 미디어이지, AI가 자동으로 채우는 미디어가 아니다.**

| 구분 | AI를 활용해 만드는 미디어 (허용) | AI가 자동으로 채우는 미디어 (금지) |
|---|---|---|
| 경험 | 운영자가 직접 한 실험이 원재료다 | AI가 만든 문장이 원재료다 |
| 사실 | 사람이 원출처로 확인한다 | AI 답변을 그대로 사실로 쓴다 |
| 판단 | 판정("쓸 만함 / 비추천")은 운영자가 한다 | AI가 판정문을 쓴다 |
| 책임 | 모든 글에 확인일과 책임자가 있다 | 누가 확인했는지 알 수 없다 |
| 속도 | 실험 속도에 맞춰 발행한다 | 생성 속도에 맞춰 발행한다 |

---

## 2. 제작 과정에서 AI 사용

### 2-1. 허용
- 자료 수집 보조 (단, 인용하는 사실은 사람이 원출처에서 다시 확인)
- 초안 구조 잡기, 목차 제안
- 비교표 정리, 기록 데이터(시간 로그 등)의 계산·정리
- 맞춤법, 문장 교정, 가독성 개선
- 번역 보조 (원문과 대조)
- 제목 후보 브레인스토밍 (최종 선택은 사람)

### 2-2. 금지
| # | 금지 행위 | 설명 |
|---|---|---|
| X1 | 직접 사용하지 않은 것을 사용한 것처럼 쓰기 | 써보지 않았으면 "미사용"이라고 쓴다 |
| X2 | 확인하지 않은 사실 게시 | 기능, 가격, 정책, 수치는 원출처와 확인일이 필요하다 |
| X3 | AI가 만든 가짜 경험 | "제가 해봤더니" 문장은 실제 실험 기록이 있을 때만 쓴다 |
| X4 | 가짜 인터뷰·가짜 사례·가짜 후기 | 실제 인물의 실제 발언만, 동의를 받아 쓴다 |
| X5 | 가짜 수익·가짜 수치 | 측정하지 않은 시간·비용·수익을 쓰지 않는다 |
| X6 | 존재하지 않는 테스트 | 테스트 조건, 스크린샷, 원자료가 없으면 TEST 형식으로 발행하지 않는다 |
| X7 | 출처 세탁 | 다른 매체·게시물의 주장을 AI로 바꿔 써서 원출처를 지우는 행위. 인용한 것은 반드시 출처를 밝힌다 |
| X8 | 재작성 대량 발행 | 다른 콘텐츠를 요약·재작성하는 것만으로 글을 발행하지 않는다 |
| X9 | AI 이미지로 실험 결과 연출 | 결과 화면은 실제 스크린샷만 쓴다. 설명용 삽화가 AI 생성이면 표시한다 |

### 2-3. 공개
- 모든 글 하단에 **"이 글의 제작에 AI를 쓴 부분"**을 한 줄로 적는다. (예: "시간 기록 표 정리와 맞춤법 교정에 ○○ 사용. 실험 수행과 판정은 운영자가 직접 함.")
- 실험 대상 AI와 제작 보조 AI가 같을 수 있다. 헷갈리지 않게 구분해서 적는다.

## 3. 실험·측정 원칙

| # | 원칙 |
|---|---|
| E1 | **사전에 설계한다.** 과제, 성공 기준, 기간, 중단 기준을 실행 전에 기록한다. 결과를 본 뒤 기준을 바꾸지 않는다. 바꿨다면 바꾼 사실을 쓴다 |
| E2 | **기준선(baseline)을 먼저 잰다.** 시간 절약을 말하려면 AI 없이 걸린 시간이 있어야 한다. 과거 기록이 없으면 "추정"이라고 쓴다 |
| E3 | **도구, 버전, 요금제, 확인일을 기록한다** |
| E4 | **실패와 수정을 숨기지 않는다.** 다시 시킨 횟수, 사람이 고친 부분을 쓴다 |
| E5 | **n=1 한계를 명시한다.** 운영자는 평균적인 초보자가 아니다(AI 사용 경험이 있다). 운영자의 조건을 공개한다 |
| E6 | **원자료를 보관한다.** 시간 로그, 스크린샷, 영수증. 개인정보를 가린 뒤 가능한 범위에서 공개한다 |
| E7 | **판정은 세 단계로 한다**: 쓸 만함 / 조건부 / 비추천. 점수를 남발하지 않는다 |
| E8 | **도구나 요금이 바뀌면 "재검증 필요"로 표시**하고, 재검증한 뒤 "업데이트됨"으로 바꾼다 |

---

## 4. 사람과 개인정보

| # | 원칙 |
|---|---|
| P1 | 실험에 타인(가족, 지인, 고객)의 개인정보를 쓰지 않는다. 필요하면 가상 자료나 본인 자료를 쓴다 |
| P2 | 다른 사람이 실험에 참여하면(예: 부모님이 카톡 ChatGPT를 써보는 과제) **사전 동의**를 받고, 얼굴·이름·목소리는 동의한 범위에서만 쓴다 |
| P3 | 스크린샷의 개인정보, 계정 정보, 회사 자료는 가린다 |
| P4 | 음성·얼굴 합성 실험은 **운영자 본인과 동의한 사람**으로만 한다. 실존 인물 사칭물은 만들지 않는다 |
| P5 | 회사 기밀이나 고객 데이터를 외부 AI에 넣는 실험은 하지 않는다 |

## 5. 돈과 이해관계

| # | 원칙 |
|---|---|
| M1 | 경제적 이해관계(제휴 링크, 협찬, 무상 제공, 체험권)는 **본문 첫 부분**에 표시한다 (추천·보증 심사지침 수준 이상) |
| M2 | **검증 대상 서비스·강의의 제휴 링크로 수익을 내지 않는다** |
| M3 | 협찬을 받은 글은 판정을 바꿀 수 없다는 조건을 사전에 서면으로 합의한다. 합의가 안 되면 받지 않는다 |
| M4 | 수익화 관련 콘텐츠는 [ai-monetization-landscape.md](../research/ai-monetization-landscape.md) §13의 R1~R14를 따른다. 핵심은 다음과 같다: 검증되지 않은 수익 숫자를 제목에 쓰지 않는다(R1), 선불 수익 보장·레퍼럴 상품은 돈을 넣어 실험하지 않는다(R6), 투자·코인은 다루지 않는다(R7), 특정 판매자를 저격하지 않는다(R12), **수익화 강의를 팔지 않는다(R13)** |
| M5 | 수익 관련 수치는 매출, 순이익, 도구비, 광고비, 투입 시간을 구분한다. 확인하지 못한 것은 **미검증 주장**으로 표시한다 |
| M6 | 세금, 법률, 의료는 공식 안내로 연결하고 개별 조언을 하지 않는다 |

---

## 6. 정정과 업데이트

- 사실 오류를 발견하면 해당 글을 고치고, 글 하단과 사이트의 **정정 로그**에 날짜와 내용을 남긴다. 조용히 고치지 않는다.
- 독자가 오류를 제보하면 확인 결과를 알린다.
- 판정이 바뀌면(예: 비추천 → 쓸 만함) 원래 판정을 지우지 않고 **변경 이력**으로 남긴다.

## 7. 쓰지 않는 표현

| 쓰지 않음 | 대신 |
|---|---|
| "검증됨(VERIFIED)", "보장", "무조건" | "근거 확인", "직접 해본 결과 (n=1)" |
| "누구나", "하루 N분으로 월 N만원" | "이런 조건의 사람에게는" + 실측값 |
| "AI 전문가가 알려주는" | "직접 ○건을 실험한 기록에 따르면" (실제 건수만) |
| "완전 자동", "딸깍" | 실제로 사람이 한 작업을 적는다 |
| "충격", "필수", "모르면 손해" 같은 공포·과장형 제목 | 문제와 결과를 그대로 쓴 제목 |
