# Target Selection Framework (Phase 2)

작성일: 2026-09-29 · 상태: **평가 틀만 있음. 점수 미입력 (인터뷰 전)**
관련 문서: [../research/phase2-target-hypotheses.md](../research/phase2-target-hypotheses.md) · [../research/phase2-interview-template.md](../research/phase2-interview-template.md)

> 이 프레임은 인터뷰 증거가 쌓인 뒤 후보 세그먼트(SEG-A~G)를 비교하는 데 쓴다.
> **지금은 어떤 점수도 넣지 않는다.** 모든 점수에는 Interview ID나 Phase 1 출처 같은 근거를 붙여야 한다.

---

## 1. 평가 항목과 정의

| # | 항목 | 질문 | 주요 증거 출처 |
|---|---|---|---|
| 1 | **Problem Strength** | 문제가 얼마나 자주, 얼마나 강하게 생기는가? | Consumer C2 (빈도, 최근성, 해결에 쓴 시간과 비용) |
| 2 | **AI Relevance** | AI가 실제로 해결책이 될 수 있는가? | C2·C3 사례 + 운영자의 직접 테스트 가능성 |
| 3 | **Return Potential** | 다시 방문할 이유가 있는가? (문제의 반복성, 정기 채널 습관) | C2-2, C4 (P3) |
| 4 | **Reachability** | 운영자가 현실적으로 도달할 수 있는가? (경로 A/B/C, 네트워크, 기관) | C3-2, C4-4, C4-6, Founder Input |
| 5 | **Content Repeatability** | 1년 이상 콘텐츠를 계속 만들 수 있을 만큼 문제의 폭이 넓은가? | 반복 문제 목록 수, 문제 다양성 |
| 6 | **Founder Fit** | 운영자의 실제 경험과 맞는가? | Founder Input (§6) |
| 7 | **Trust Opportunity** | 활동 기록(테스트, 실험, 강의)으로 신뢰를 쌓을 수 있는가? | C6-6 (신뢰 기준), Buyer B4 |
| 8 | **Education Fit** | 교육으로 자연스럽게 이어지는가? | C5, C6-7, Buyer B2 |
| 9 | **Payment Signal** | 개인이나 기관의 지불 신호가 있는가? **(누가 내는지 구분)** | C6-7, C5-7, Buyer 전체 |
| 10 | **Solo Operability** | 1인이 지속 운영할 수 있는가? (필요한 콘텐츠 형식, 사실 검증 부담, 채널 수) | 채널 요구사항 + Founder Input (시간, 형식) |

## 2. 평가 척도 (0~3, 증거 기반)

| 점수 | 의미 |
|---|---|
| **0** | 반박 증거가 있음 (인터뷰에서 반대 패턴이 반복됨) |
| **1** | 증거 없음 또는 단일 사례뿐 |
| **2** | 서로 다른 인터뷰 2건 이상에서 지지 패턴이 확인됨. 반례가 있으면 함께 기록 |
| **3** | 여러 Context에서 반복 확인되고, 행동 증거(실제 지출, 정기 이용 기록, 구매 이력)가 뒷받침함 |
| **?** | 해당 세그먼트 인터뷰 부족 (평가 보류) |

- **점수마다 근거 ID 필수**: 예) `Return Potential = 2 (C-02, C-06 / 반례 C-09)`
- 기대, 추측, 운영자의 선호로 점수를 올리지 않는다.
- 연구자가 두 명 이상이면 각자 매긴 뒤 차이를 토론한다(1인이면 하루 뒤 재검토).

## 3. 관문 기준 (Gate)

점수 합계보다 먼저 확인한다. **하나라도 0이면 후보에서 제외하거나 보류**한다.

| 관문 | 이유 |
|---|---|
| Problem Strength ≥ 1 | 문제가 없으면 나머지는 의미가 없다 |
| Reachability ≥ 1 | Phase 1의 핵심 위험이 도달 문제였다 (Acquisition Paradox) |
| Solo Operability ≥ 1 | 1인 운영이 전제다 |

## 4. 가중치

**미리 확정하지 않는다.** 인터뷰 후 다음을 기본값 후보로 검토한다.
- Phase 1에서 가장 약했던 고리인 **Return Potential, Reachability, Payment Signal**에 추가 가중을 검토한다.
- Founder Fit은 **보조 기준**이다. 동점이거나 근소한 차이일 때 판단에 쓰고, 증거가 약한 세그먼트를 끌어올리는 데 쓰지 않는다.

**결정 규칙 (초안)**
1. 관문을 통과한 후보만 비교한다.
2. 최종 타깃은 **주 타깃 1개**와 필요하면 **확장 타깃 1개**로 한다. 여러 개를 동시에 타깃으로 잡지 않는다(1인 운영 제약).
3. 결정 문서에는 선택 이유, 버린 후보와 이유, **아직 약한 증거**를 함께 적는다.
4. 결정은 사용자 승인 후 확정한다.

## 6. Founder Input 템플릿

> **목적**: 타깃 결정의 보조 기준(Founder Fit, Reachability, Solo Operability)을 채우는 것이다.
> 운영자 정보를 **추측하지 않는다.** 의사결정에 필요한 수준으로만 묻는다. 가족 구성이나 건강 같은 불필요한 개인정보는 요구하지 않는다.
> 운영자가 직접 작성한다. 모르거나 정하지 않은 항목은 `미정`으로 둔다.

| # | 항목 | 답 | 어떤 판단에 쓰나 |
|---|---|---|---|
| F1 | 현재 주요 업무와 산업 경험 (분야, 기간 정도) | | Founder Fit (어느 Context와 가까운가) |
| F2 | AI를 실제로 업무나 생활에서 쓰는 방식 (주로 쓰는 도구와 용도, 빈도) | | Trust Opportunity, 직접 테스트 가능 범위 |
| F3 | 일반인에게 AI를 설명하거나 교육한 경험 (횟수와 대상. **실제 있었던 것만**) | | Education Fit, 이력의 출발점 |
| F4 | 직접 테스트할 수 있는 생활·업무 영역 (예: 문서 업무, 가게 운영, 행정 서류, 콘텐츠 제작 등) | | AI Relevance, Content Repeatability |
| F5 | 주당 프로젝트 투입 가능 시간 (1년 이상 지속 기준) | | Solo Operability (Phase 1 추정: 주 16~27시간) |
| F6 | 월 실험·운영 예산 범위 | | G5 실험 범위, 인터뷰 사례비 |
| F7 | 가능한 콘텐츠 방식: 텍스트 / 이미지 / 음성 / 영상 (얼굴 공개 여부 포함) | | 채널 적합성 (P3 결과와 대조) |
| F8 | 강의 가능 여부: 오프라인(가능 지역) / 온라인 | | Reachability (경로 C), Education Fit |
| F9 | 인터뷰 대상 모집 가능 범위 (어떤 Context의 사람을 몇 명 정도 소개받을 수 있나) | | Phase 2 실행 가능성, 표본 편향 점검 |
| F10 | 기관·기업 교육 담당자 접촉 가능성 (Buyer Track) | | P5 검증 가능성 |
| F11 | 장기간 다루고 싶은 AI 주제와 다루고 싶지 않은 주제 | | Content Repeatability, 지속 동기 |
| F12 | AI 수익화 콘텐츠에 대한 입장 (Phase 1 편집 원칙 R1~R14 수용 여부) | | G5 비중 결정 |
