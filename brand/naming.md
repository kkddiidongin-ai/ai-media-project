## 1. 핵심 개념에서 이름으로: 장단점

| 개념 | 이름으로 썼을 때 장점 | 이름으로 썼을 때 단점 |
|---|---|---|
| 확인 | 정체성과 가장 정확히 맞음 | 딱딱하고 행정적(확인서, 확인필). 팩트체크 기관처럼 보일 수 있음 |
| 직접 | 차별점이 선명함 | 부사라 명사형 이름이 되기 어려움 ("직접AI"는 어색) |
| 써봄 / 해봄 | 구어적이고 친근함, "직접 해봤다"가 바로 전달됨 | "-봄"으로 끝나는 브랜드가 이미 많음(해봄, 손봄, 마켓봄 등). 써봄은 체험단 연상 |
| 실험 | 호기심과 실험 정신 | "실험실·Lab"은 연구기관 인상이라 피할 이미지와 충돌 |
| 기록 | 계속 쌓인다는 것 | 단독으로는 AI·일과의 연결이 약함 |
| 변화 | 넓은 범위 | 추상적, 뉴스 느낌 |
| 일 / 생활 | 과제 중심 | 일반명사라 검색에 묻힘 |
| 실제 / 실사용 | "실사용 후기"라는 익숙한 표현 | 리뷰 사이트 느낌, 검색에 묻힘 |
| 체크 / 검증 / 측정 | 신뢰 | 딱딱함, 기관처럼 보임 |
| 결과 | 결과 중심 | 추상적 |
| 다음 | 계속된다는 느낌 | 추상적, 미래지향 테크 느낌 |

→ **"해보다/써보다/시켜보다"(시도)**와 **"보고·기록"(축적)**을 결합할 때 이름으로 가장 잘 작동한다.

## 3. 한국어 vs 영어 vs 혼합형

| 기준 | 한국어 이름 | 영문 이름 | 한국어 발음 기반 조어·혼합형 |
|---|---|---|---|
| 기억 | **높음** (말로 전해짐: "○○에서 봤는데") | 낮음~중 | 중~높음 |
| 검색 | 일반어면 묻힘, 조어면 유리 | 일반 영어 단어면 묻힘 | **유리** (고유 조어) |
| 신뢰 | 친근하고 투명함 | 전문적이지만 거리감 | 중간 |
| 미디어 느낌 | 중 (descriptor로 보완) | 높음 | 중 |
| 확장성 | 교육·기관 강의에서 말하기 쉬움 | 해외 확장에 유리 (현재 목표 아님) | 중 |
| 일반 사용자 접근성 | **높음** | 낮음 (30~60대에게 발음·철자 부담) | 중~높음 |

**판단**: **한국어 구어를 비튼 조어**를 권한다. 일반 단어를 그대로 쓰면 검색에 묻히고, 영문은 핵심 독자와 멀다.
- **AI를 이름에 넣지 않는다.** 대신 "AI 실용 미디어" 같은 설명형 부제(descriptor)를 함께 쓴다. AI를 넣으면 즉시 알아보는 장점이 있지만, AI 사이트가 너무 많아 변별력이 없고, 기술 명칭이 바뀌면 이름이 낡는다.
- 영문 표기는 도메인과 로고 보조용으로만 쓴다. 로마자 표기가 길어지는 문제는 도메인 단계에서 따로 판단한다.

## 7. Naming Shortlist (3개 방향, 순위 없음)

비슷한 이름을 철자만 바꿔 늘리지 않도록, **방향이 다른 3개**만 남겼다. 시켜봄과 맡겨봄은 같은 방향의 두 표현이라 하나로 묶었다.

### 7-1. 해보고서
- **어떤 브랜드가 되나**: "해보고, 남긴다"는 **기록형 AI 실용 미디어.** 글 하나하나가 "해보고서 한 편"이 된다.
- **가장 강한 장점**: 직접 해봄(해보고서)과 기록(보고서)이 한 단어에 있다. 결과가 성공이든 실패든 **중립적**이라 "솔직함"과 충돌하지 않는다. 과제 중심 동사("해보다")를 쓴다.
- **가장 큰 약점**: 4음절이고, 처음 들으면 "보고서 써주는 곳"으로 오해할 수 있다. 부제("AI 실용 미디어")가 반드시 필요하다.
- **어울리는 시각 방향**: 에디토리얼 + 현장 기록장 (보고서 양식, 날짜, 확인 표시)
- **교육 연결**: 참가자가 **자기 일로 "해보고서"를 직접 써보는 워크숍** 구조가 자연스럽다. 강의가 미디어의 방법을 그대로 가르치는 형태라 판매 사이트처럼 보이지 않는다.

### 7-2. 시켜봄 (변형: 맡겨봄)
- **어떤 브랜드가 되나**: "AI에게 내 일을 시켜보는" **생활·업무 실험 미디어.** 가볍고 생생하다.
- **가장 강한 장점**: 짧고, 말로 전하기 쉽고, 사람이 AI에게 일을 맡기는 장면이 바로 떠오른다.
- **가장 큰 약점**: "AI가 다 해준다"는 자동화 인상을 줄 수 있어 "확인한 만큼만"과 긴장이 생긴다. "-봄" 브랜드가 많아 변별력이 약하다. "시켜 먹다" 연상도 있다(맡겨봄이면 완화되지만 돌봄 연상).
- **어울리는 시각 방향**: 생활 도구형 + 에디토리얼
- **교육 연결**: "내 일, AI에 시켜보기" 실습형 입문 교육과 잘 맞는다.

### 7-3. 해봤더니
- **어떤 브랜드가 되나**: "해봤더니 이랬다"를 말하는 **대화형 실용 미디어**
- **가장 강한 장점**: 직접 경험을 전하는 한국어 어미 그대로라 가장 솔직하게 들린다. 제목과 연재에 붙이기 좋다("해봤더니: 회의록 편").
- **가장 큰 약점**: 명사가 아니라서 "○○에서 봤어"처럼 브랜드로 부르기 어색하다. 일반 구어라 검색에 가장 불리하다.
- **어울리는 시각 방향**: 현장 기록장
- **교육 연결**: 약함. **다른 브랜드명 아래의 연재명이나 코너명**으로 쓰는 편이 더 효과적일 수 있다.

**권고 의견 (확정 아님)**: 브랜드명 1순위 검토 대상은 **해보고서**다. 정체성(해봄 + 기록), 결과 중립성, 교육 연결이 가장 잘 맞는다. **해봤더니**는 브랜드명보다 **글 연재·주간 노트의 코너명** 후보로 보관할 것을 제안한다.
