# Phase 2 인터뷰 증거 기록 템플릿

작성일: 2026-09-29 · 관련 문서: [phase2-interview-guide.md](phase2-interview-guide.md) · [phase2-target-hypotheses.md](phase2-target-hypotheses.md)

> **기록 규칙**
> 1. **Quote는 실제 인터뷰 발언만** 녹음이나 메모에서 그대로 옮긴다. 요약하거나 다듬은 문장은 Quote 칸에 쓰지 않는다. 가상의 발언은 절대 쓰지 않는다.
> 2. **관찰(말한 것, 한 것)**과 **해석(연구자 판단)**을 다른 칸에 쓴다.
> 3. 확인하지 못한 항목은 비워두지 말고 `미확인` 또는 `해당 없음`으로 쓴다.
> 4. 이름·연락처는 쓰지 않는다. ID만 쓴다.
> 5. 인터뷰 1건당 파일 1개를 권장한다. 예: `research/interviews/C-01.md`. **이 폴더는 실제 인터뷰가 생길 때 만든다.**

## 3. 종합 집계표 (인터뷰가 쌓인 뒤 작성)

인터뷰가 없는 상태에서는 **빈 표로 둔다.**

### 3-1. Consumer 집계

| ID | Stage | 플래그 | Context | 주요 Problem | 중단 이유 | 재사용 계기 | 정기 채널 | 검색 종료 지점 | P1 | P2 | P3 | P4 | 경로 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | | | |

### 3-2. Buyer 집계

| ID | 기관 유형 | 탐색 경로 | 먼저 말한 선정 기준 | 후속 지원 예산 | 재계약 기준 | P5 |
|---|---|---|---|---|---|---|
| | | | | | | |

### 3-3. 패턴 메모 규칙
- 패턴은 **서로 다른 Context에서 2건 이상** 반복될 때만 "패턴"으로 쓴다. 1건은 "사례"로 쓴다.
- 반례는 반드시 함께 쓴다.
- 결론에는 근거가 된 Interview ID를 붙인다(예: "재사용 계기 = 사람의 권유: C-03, C-07, C-11 / 반례: C-05").
